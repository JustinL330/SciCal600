Native app availability

Downloads and platform limits

The calculator core is shared across Web, Android, Windows, macOS and iOS. Testing downloads are published on GitHub only after their cloud checks pass.

A

Android

Verified, development-signed testing APK. Android may ask you to allow installation from this source. A production release requires the protected production signing key.

W

Windows

Testing installer and portable EXE. They are not commercially code-signed yet, so Microsoft SmartScreen may show a warning.

M

macOS

Intel and Apple-silicon testing archives. They are not Developer ID signed or notarized yet, so Gatekeeper may require manual approval.

i

iOS / iPadOS

Simulator build plus an unsigned device archive for later signing. Installing an IPA on a physical device requires Apple signing and provisioning. The Web app can still be added to the Home Screen from Safari.
