Instruction bits

This project-defined teaching format stores the opcode in the upper 16 bits and the LOAD/STORE address in the lower 16 bits. IN/OUT use simulator-specific encodings.

Program & memory

The default demo demonstrates a complete transfer sequence in 38 steps. Enter one instruction per line: IN R0, OUT ACC, LOAD [address], STORE [address], ADD, SUB, or NEG. Use DATA address value to initialize memory. Applying the program restarts execution from the first step.

This project-defined teaching architecture visualizes register, memory, ALU, I/O, and control-bus transfers. ADD computes ACC + R0; SUB computes ACC − R0; NEG computes −ACC. Arithmetic uses signed 32-bit integers.
