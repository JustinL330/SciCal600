Instruction bits

Lecture slides 18 and 24: the upper 16 bits contain the opcode; the lower 16 bits contain the LOAD/STORE address. IN/OUT are teaching extensions from the video; their binary encodings are not specified in the slides.

Program & memory

The default demo reproduces the video in 38 steps. Enter one instruction per line: IN R0, OUT ACC, LOAD [address], STORE [address], ADD, SUB, or NEG. Use DATA address value to initialize memory. Applying the program restarts execution from the first step.

Recreated from the supplied video (approximately 75 seconds), Lecture 4 (slides 15, 18, 24–25, 30–32 and 35), and the LOAD instruction photo. ADD: ACC + R0; SUB: ACC − R0; NEG: −ACC. Arithmetic uses signed 32-bit integers.
